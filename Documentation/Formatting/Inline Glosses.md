Inline glosses attach a description to a term in prose. Write `{term::description}` or `{ term :: description }`. Tangent shows the term on a darker background with a small information indicator; hovering shows its description immediately.

The base and description are plain text. Formatting can surround the gloss, but Markdown inside either field remains literal. Glosses stay on one line and cannot be nested. Moving the caret into a gloss reveals its original source for editing.

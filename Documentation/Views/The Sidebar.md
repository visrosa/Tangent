The Sidebar shows a tree of all supported files and folders (see [[The Workspace]] for the list of supported file types).

Click on any folder or file to open it. You can also Command or Control click to add the file to the end of your current thread.

Double clicking on a file or folder will let you rename it in place.

You can move files and folders by dragging them to a new folder in the sidebar.

The right click context menu on the files and folders let you rename, delete, locate the file in Explorer or Finder, and add sub folders and sub files.

At the top of Files & Folders, the toolbar contains sorting, current-level folder expansion, all-folder expansion, and new-root-folder buttons, in that order.

The single-folder button toggles folders at the current level: the siblings of the last tree row you focused, or of the selected item if you have not focused a row. With no usable row, it targets root folders. Its tooltip names the parent folder. Focusing a folder row targets that folder and its siblings; focusing a file targets the folders beside that file. When a row is hidden by a collapsed ancestor, the nearest visible ancestor determines the level.

The stacked-folder button toggles all folders, including descendants under closed folders. Both buttons collapse their target folders if any are expanded; otherwise they expand them. The current-level button preserves deeper expansion states, so reopening the level restores those branches. The all-folder button sets every displayed folder's expansion state together. These controls follow the sidebar's display filters and do not affect files or the current thread. Expansion states are saved with the workspace view.

Use Tab to move through toolbar buttons and Enter or Space to activate them. A button is disabled when its scope contains no folders. Tags keep their separate sorting control.
